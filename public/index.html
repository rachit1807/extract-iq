A QUICK FIELD GUIDE

Find the signal.

Presets target common page structures. Different websites use different HTML, so a preset may need a custom rule.

  1. Choose the repeating element. For example, .product_pod on the sample bookshop.
  2. Map the fields inside it. Use h3 a for a title and .price_color for a price.
  3. Pick what to read. Text for labels, href for links, src for image URLs.
  4. Inspect before exporting. Search the rows, hide columns, and select what you need.

Only server-delivered HTML is parsed. Content loaded by JavaScript, login-protected pages, CAPTCHA pages, and websites that block automation are not supported. Pagination stays on the same website. Limits: 3 pages, 1,000 rows, and 2 MB per page.
